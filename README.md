## 🛠️ Development Guidelines

If you are exploring the code or contributing to the architecture, please note my current workflow guidelines:

1. **Preserve Functionality:** The existing design system and interactive elements (e.g., mouse effects, sound providers) should remain intact.
2. **Prioritize Identity:** Personal information, SEO metadata, and the homepage take precedence over secondary pages.
3. **Local Testing:** Always test changes locally (`npm run dev`) before staging.
4. **Branching:** Do not push directly to `main` until feature customization is fully tested and reviewed.
